In Blender:
  1. Select object(s) with same material
  2. File → Export → Export as PLY (.ply)
  3. Name: {material_name}.ply
     Examples: mat-itu_brick.ply, mat-itu_concrete.ply
  4. Save to: .../Nottingham_Sionna2_v1/meshes/
  5. Repeat for each material

Or use Python script in Blender Python console:
```python
import bpy, os
export_dir = "/home/georgeskai/Documents/FYP2026/nottingham900/Nottingham_Sionna2_v1/meshes"
os.makedirs(export_dir, exist_ok=True)
for obj in bpy.context.scene.objects:
    if obj.type == 'MESH':
        bpy.context.view_layer.objects.active = obj
        obj.select_set(True)
        mat_name = obj.data.materials[0].name if obj.data.materials else "default"
        ply_path = os.path.join(export_dir, f"{mat_name}.ply")
        bpy.ops.export_mesh.ply(filepath=ply_path)
        obj.select_set(False)
```
