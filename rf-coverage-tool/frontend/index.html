    Notes

    • Received level = Ptx + Gtx − Lf,tx + pattern(azimuth) − Lb + Grx − Lf,rx. The server computes only Lb, so power, gains, pattern and colours redraw instantly.
    • ITU-R P.1812-8: full method (LoS with multipath/focusing, delta-Bullington diffraction, troposcatter, ducting/layer reflection), time % and location %. ΔN and N0 from the ITU maps; k is derived from ΔN. Validated against the ITU-R SG3/Ofcom test set on land paths. Land paths only in this tool.
    • Delta-Bullington (P.526-16 §4.5) and single knife-edge (P.526): median loss using the k entered.
    • RX environment: ITU-R P.2108 §3.1. The path is computed with the receiver raised to the representative clutter height R and the height-gain or diffraction correction Ah is added (0.03-3 GHz).
    • Terrain: AWS Terrain Tiles (EA 2 m LiDAR DTM over England; SRTM and others elsewhere) or your own DTM in data/dtm/. Clutter (DSM − DTM) needs local DSM tiles in data/dsm/.
    • Drive test: error statistics compare the coverage raster (nearest pixel) with the measured column.
    • Planning aid only. Verify critical links with measurements.
